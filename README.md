

Data, metadata, and code supporting Flenniken et al. 2026. Current Gaps and Future Threats to Say’s Spiketail Habitat in the Southeastern USA. Ecology and Evolution.

Code and analytical workflows generated by Mark A. Barrett.

Due to legal restrictions associated with the sharing of biologically sensitive data, occurrence records provided by the Georgia Department of Natural Resources have been removed from the archived dataset; the full dataset was made available for peer review.
